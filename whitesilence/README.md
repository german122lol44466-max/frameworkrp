# SCP: Белая тишина

Фреймворк-гейммод для Garry's Mod во вселенной SCP. Первый модуль — кинематографичное интро при входе на сервер.

## Установка

Два архива из `dist/`, оба распаковываются в папку `garrysmod/` сервера:

| Архив | Что внутри | Куда попадёт |
|---|---|---|
| `whitesilence_gamemode.zip` | код режима | `garrysmod/gamemodes/whitesilence` |
| `whitesilence_content.zip` | картинки, звуки, шрифты | `garrysmod/addons/whitesilence_content` |

Запуск: `+gamemode whitesilence +map <любая карта>`.
Контент раздаётся клиентам через FastDL (`core/sv_resources.lua`) или его можно залить в Workshop (`addon.json` уже есть).
Шрифты GMod подхватывает только при запуске игры: игроку, скачавшему их при первом входе, красивые шрифты
покажутся со второго запуска (в Workshop-подписке этого нет).

## Интро (~53 с, [ПРОБЕЛ] — пропустить)

| Время | Кадр | Звук |
|---|---|---|
| 0–3 с | Заставка: темнота, сквозь неё летит снег, холодное свечение, надпись «Фонд SCP · Восстановленная запись», красная черта | нарастающий ветер, низкий гул, далёкий гром, обрывок эфира |
| 2–14 с | Арктика в метели, отряд МОГ «Дельта-14» идёт колонной, камера медленно наезжает. Через секунду: «Арктика. Метель. МОГ «Дельта-14» была на задании по сдерживанию аномального объекта.» | метель |
| 15–22 с | Затемнение, отряд вблизи: стоят неподвижно и смотрят прямо в камеру. «Но что-то в них было уже не так...» В очках разгорается бледный отблеск | удар, тревожный гул, сердцебиение |
| 22–33 с | Рука погибшего бойца в снегу, кровь, рядом рация с мигающей лампочкой. «Купол» вызывает «Дельту-14». «Они все — были мертвы. Их сигнал пропал ещё неделю назад.» | рация с помехами, тише метель |
| 33–45 с | В вертолёте: боец в шлемофоне смотрит в окно, рядом летит второй борт, вибрация, за стеклом летит снег. «Ты — сотрудник спецподразделения. Твоя задача — нейтрализовать данных существ, которые притворяются отрядом.» | вертолёт изнутри |
| 45–53 с | Знак Фонда SCP, «Обезопасить. Удержать. Сохранить.» | финальный удар |

Кадры — цифровой концепт-арт крупными мазками (нарисованы нейросетью Stable Diffusion XL в стиле присланных референсов).
Субтитры — как в кинематографичных заставках: снизу по центру, капитель Alegreya Sans SC, ключевые слова золотистым,
тёмная полоса с цветной подсветкой под текстом. Кадры проявляются мазками кисти от центра к краям (камера при этом
чуть «оседает») и так же закрываются к центру. Эффекты: метель из частиц с глубиной и ледяной крошкой, два слоя
тумана, медленный наезд камеры, проявление кадра из размытого, зерно, виньетка, тряска в вертолёте.
Пока идёт интро, сервер держит игрока замороженным и неуязвимым.

| Команда / квар | Что делает |
|---|---|
| `ws_intro` | показать интро ещё раз |
| `ws_intro_mode 0/1/2` | клиент: никогда / только в первый раз / при каждом входе (по умолчанию 2) |
| `ws_intro_force 1` | сервер: показывать всем при каждом входе |
| `ws_volume 0..1` | громкость звуков режима |

Тексты, тайминги и звуковые метки — в `modules/intro/cl_config.lua`.

## Структура

```
gamemodes/whitesilence/gamemode/
  core/      конфиг, утилиты и сглаживания, шрифты, звук с плавной громкостью, UI (текст с проявлением), раздача контента
  modules/   системы; каждая папка подключается целиком (sh_ / sv_ / cl_)
    intro/   cl_config (сценарий), cl_fx (снег, туман, зерно), cl_intro (проигрыватель), sv_intro (заморозка)
content/     materials/whitesilence, sound/whitesilence, resource/fonts, LICENSES
tools/       генерация картин (SDXL) и звуков, обработка, сборка архивов, проверки
dist/        архивы для установки
```

## Пересборка и проверка

```
python3 tools/content/gen_paintings.py    # картины нейросетью SDXL (torch, diffusers; модель — Docker Hub ai/stable-diffusion)
python3 tools/content/intro_art.py        # обработка картин, знак Фонда из SVG, текстуры (numpy, Pillow, resvg-py)
python3 tools/content/intro_audio.py      # звуки (numpy, scipy, ffmpeg, sherpa-onnx для голоса)
python3 tools/content/make_archive.py     # dist/*.zip
python3 tools/test/intro_sim.py           # прогон интро без игры: ошибки Lua, nil в отрисовке, пропавшие файлы
python3 tools/test/intro_frames.py        # кадры интро в картинки — как их нарисует игра
```
