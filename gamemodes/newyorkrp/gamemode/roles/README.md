# Роли

Каждый файл `<id>.lua` в этой папке — одна роль. Имя файла — её id (для команды `/setrole`).

```lua
ROLE.Name = "Гражданин"            -- название
ROLE.Description = "..."           -- описание (видно в меню C → Информация)
ROLE.Color = Color(120, 214, 110)  -- цвет названия
ROLE.Icon = "user"                 -- иконка (materials/nyrp/icons/<имя>.png)
ROLE.Default = true                -- стартовая роль (ровно одна)
ROLE.Model = nil                   -- модель роли: строка или { мужская, женская }; nil — модель персонажа
ROLE.Salary = 0                    -- зарплата каждую игровую полночь на банковскую карту
ROLE.Items = { "radio" }           -- предметы при назначении роли (id из папки items/)
ROLE.Whitelist = true              -- назначает только администрация
```

Назначить: `/setrole <часть имени персонажа> <id роли>` (админ).
